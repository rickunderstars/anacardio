# AnaCardio

_AnaCardio_ is a prototype web app for the visualization of cardiac data.
It can visualize a subset of the data contained in files that adhere to the _Biosense Webster Triangulated Mesh file format_ (examples are available in `public/example-meshes`).
The app can be accessed [here (unimi)](https://mips.di.unimi.it/anacardio/) or [here (GitHub Pages)](https://rickunderstars.github.io/anacardio/).
_AnaCardio_ is completely client-side, running locally on the user's machine.

## Features

- Load multiple meshes;
- Orbit camera controls + 6 standard views;
- 3 rendering modes;
- 7 sets of data extracted per mesh + 1 combined set;
- Real time ray-cast sampler bound to cursor position;
- Legend with updating markers that follow the sampler output;
- Sliders to modify the render output;
- Screenshot tool.
